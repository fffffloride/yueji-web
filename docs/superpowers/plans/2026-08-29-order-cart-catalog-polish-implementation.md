# 订单、购物车与商品目录细节修正实施计划

日期：2026-08-29  
依据：`docs/superpowers/specs/2026-08-29-order-cart-catalog-polish-design.md`

## 1. 后端固定商品分组

- 在现有 `appCatalog()` 内复用已加载商品，按“推荐 / 热卖 / 新品”标签生成三个固定分组并置顶。
- 返回 `fixed: true` 与始终存在的单 section，普通分类继续过滤空分组。
- 扩展商品服务测试，覆盖固定顺序、标签映射、重复商品和空固定分组。

## 2. 前端目录与商品卡

- 扩展目录分组类型与疼痛友好过滤，固定分组过滤后仍保留。
- 固定分组无商品时显示局部空提示。
- 从共享商品卡移除标题右侧标签展示，保留标签数据。

## 3. 确认页与购物车

- 给备注输入框启用自动高度。
- 将购物车勾选框垂直居中。
- 商品图片和信息区使用现有路由进入商品详情，数量、删除和勾选操作保持独立。

## 4. 验收与交付

- 运行后端商品服务测试、构建和触及文件 lint。
- 在 `375×812`、`430×932` 验证三个页面及主要交互。
- 运行前端 `pnpm verify:ui`、两仓库 `git diff --check`，分别精确提交。
