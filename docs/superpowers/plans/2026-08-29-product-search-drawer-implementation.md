# 商品列表全屏搜索抽屉实施计划

## 任务 1：迁移搜索入口与交互

- 修改 `src/pages/product/index.vue`。
- 在目录上方增加独占一行的“搜项目”入口。
- 使用现有 `wd-popup` 从右侧打开 100vw × 100vh 抽屉。
- 迁入现有搜索页的接口调用、本地历史、分页和商品跳转逻辑。
- 抽屉初始只显示历史，搜索后只显示结果，清空输入恢复历史。

## 任务 2：覆盖全屏

- 修改 `src/pages.json`，将商品页改为自定义导航。
- 在商品页和搜索抽屉内分别补齐最小导航栏，并处理状态栏安全距离。
- 系统返回优先关闭抽屉，不离开商品页。

## 任务 3：删除废弃入口

- 删除未被调用的 `src/pages-sub/product/search/index.vue`。
- 从 `src/pages.json` 和 `src/constants/routes.ts` 删除对应路由。

## 任务 4：验证

- 运行格式、类型检查和微信小程序构建。
- 在 375px 与 430px 视口验证入口宽度、全屏覆盖、历史态、结果态和无横向溢出。
- 检查并提交最终差异。
