# “我的”页会员卡重设计

日期：2026-09-02  
状态：已确认

## 1. 目标

重做“我的”页会员卡的视觉结构与等级辨识度：移除 Hero 右上角的“更多、扫码”按钮；采用已确认的 B 版独立身份卡结构；根据会员等级展示不同材质配色。

本次不修改会员等级、预约统计和会员中心的数据来源及业务路由。

## 2. 页面结构

- Hero 保留现有雾绿晨光背景，不再展示右上角操作按钮。
- 主卡上部保留昵称和 `welcome back` 问候信息。
- 会员身份区域改为完整的横向会员卡，展示等级名称、等级编号、品牌文字和成长进度。
- “待预约、待到店、服务记录”从主卡拆出，作为紧邻主卡下方的独立统计条。
- 统计条仍属于 `YjMineMemberCard` 组件，继续复用现有点击事件，不增加新组件。

## 3. 等级配色

按后台返回的 `level.code` 选择配色：

- `L1` 普通会员：米杏材质，深棕文字。
- `L2` 白银会员：冰银蓝材质，蓝灰文字。
- `L3` 黄金会员：香槟金材质，深金文字。
- `L4` 白金会员：黑铂绿材质，香槟金文字。
- `L5` 以上、非标准编号或后台自定义等级：紫晶材质兜底。
- 未登录或暂无等级：使用当前品牌雾绿中性色，不冒充具体等级。

配色仅影响视觉，不改变后台等级名称和编号。等级名称始终以接口数据为准。

## 4. 组件与交互

### `YjMineMemberCard`

- 删除 Hero 操作按钮及 `more`、`scan` 事件。
- 保留 `login`、`member`、`unlock` 和 `stat` 事件。
- 登录后点击问候区进入会员中心；未登录时进入登录流程。
- 点击会员身份卡进入会员中心。
- 三个统计项继续按现有索引触发 `stat` 事件。
- 成长进度继续复用 `memberLevelProgress`，卡片显示整数百分比并限制在 `0–100%`。

### `pages/mine/index`

- 删除 `more`、`scan` 监听和不再使用的“敬请期待”处理函数。
- 其余快捷入口、服务入口、退出登录和悬浮咨询按钮保持不变。

## 5. 配色映射

在现有会员等级工具文件中增加一个最小纯函数，将等级编号转换为 `l1`、`l2`、`l3`、`l4`、`custom` 或 `guest` 视觉标识。组件使用该标识绑定样式类。

编号匹配忽略大小写和首尾空格；仅完整匹配 `L` 加正整数。这样后台新增 `L5`、`L6` 时自动进入紫晶兜底，异常字符串不会误用已知等级配色。

## 6. 边界与降级

- 长等级名称单行截断，不挤压等级编号。
- 数据请求失败或等级为空时使用中性卡面和 `—` 编号。
- 最高等级仍显示 `100%`，没有下一等级时不展示虚假的升级目标。
- 卡片使用 CSS 渐变和几何装饰，不新增图片素材、动画库或第三方依赖。
- 会员卡和统计条在窄屏下保持单列且无横向溢出。

## 7. 验收

- Hero 右上角不再出现“更多、扫码”按钮。
- 主卡、独立会员身份卡和统计条层级与确认稿 B 一致。
- `L1–L4` 分别显示米杏、冰银蓝、香槟金、黑铂绿；自定义等级显示紫晶色；未登录显示中性色。
- 点击问候区、会员卡和统计项的既有跳转行为正常。
- `375×812` 与 `430×932` 下无横向溢出，悬浮咨询按钮仍可正常拖动、吸边和跳转。
- 配色映射自检、`pnpm verify:ui`、H5 构建和微信小程序构建通过。

## 8. 不做事项

- 不增加后台卡面颜色配置字段。
- 不为每个等级引入图片素材或徽章资源。
- 不抽取只有一个调用方的新会员卡组件。
- 不修改会员等级、折扣、累计消费或预约业务规则。
