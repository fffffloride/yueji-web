# “我的”页背景与悬浮咨询按钮设计

日期：2026-09-02  
状态：已确认

## 1. 目标

重新设计“我的”页顶部与整体背景，采用已确认的 A「雾绿晨光」方向；移除顶部“咨询/预约”按钮，将咨询入口改为右下角可拖动悬浮按钮。

本次只调整页面视觉与咨询入口交互，不改变会员等级、快捷工具、服务入口、退出登录和预约业务流程。

## 2. 视觉方向

- 页面背景由当前浅灰色改为浅雾绿到页面灰白色的纵向渐变。
- Hero 使用浅雾绿柔光层次和低对比度圆弧装饰，移除当前灰色水泡效果。
- 会员卡继续叠放在 Hero 下方，改为轻透白底、细描边和柔和阴影；保证等级名称、进度和统计信息对比度。
- 顶部仅保留右侧“更多”和“扫码”圆形按钮。
- 快捷工具、服务入口和退出登录沿用现有结构，统一调整为与新背景匹配的白色卡片和轻阴影。
- 继续使用现有墨绿主题变量，不新增图片素材或设计依赖。

## 3. 悬浮咨询按钮

咨询入口放在页面级，而不是会员卡组件内部：

- 默认位于右下角、自定义 TabBar 上方。
- 外观为墨绿胶囊按钮，包含咨询图标和“咨询/预约”文字；点击区域满足最小可触控尺寸。
- 使用 uni-app 原生 `movable-area` 与 `movable-view`，支持 H5 和微信小程序。
- 拖动范围排除页面标题栏、TabBar 和底部安全区，避免遮挡系统及导航操作。
- 松手后吸附到最近的左或右边缘，保留当前垂直位置。
- 拖动结束不触发预约跳转；未发生有效拖动时点击才进入现有 `RoutePath.APPOINTMENT`。
- 位置不写入本地存储；离开后重新进入页面时恢复右下角默认位置。

## 4. 组件与状态

### `YjMineMemberCard`

- 删除咨询按钮和 `consult` 事件。
- 保留右上角操作、用户信息、等级进度和统计事件。
- 更新 Hero、装饰层、会员卡背景与阴影样式。

### `pages/mine/index`

- 增加页面背景容器。
- 在页面级放置 `movable-area / movable-view`，继续复用现有 `handleConsult` 跳转。
- 页面就绪后测量拖动区域和按钮尺寸，设置右下角初始坐标。
- 记录拖动产生的坐标；松手时调用纯吸边计算函数更新横坐标。
- 当拖动事件来自用户触摸且累计位移超过 `4px` 时，抑制紧随其后的点击。

### 纯计算函数

增加最小工具函数，根据当前横坐标、可移动最大横坐标和边距返回左/右吸附位置。函数不访问页面状态，便于用 Node `assert` 自检。

## 5. 边界与降级

- 坐标和进度均限制在可移动范围内，窗口尺寸异常时不产生负值。
- 测量暂未完成时按钮使用远端坐标交由原生边界钳制，随后修正为右下角。
- 页面内容滚动不改变悬浮按钮位置。
- 长昵称和长等级名称继续截断，不挤压右上角操作按钮。
- 未登录状态仍可看到咨询入口；点击直接进入现有预约页。
- 更多和扫码仍保持当前“敬请期待”行为。

## 6. 验收

- `375×812` 与 `430×932` 下无横向溢出，会员卡、背景和悬浮按钮层级正确。
- 按钮默认位于右下角且不覆盖 TabBar；可拖到上下边界和左右两侧。
- 松手后正确吸附最近边缘；拖动不跳转，轻点进入预约页。
- 页面离开后重新进入，按钮恢复右下角。
- 页面滚动、会员数据成功/失败和未登录状态下按钮仍可操作。
- 控制台无新增错误；运行纯函数自检和 `pnpm verify:ui`，覆盖 H5 与微信小程序构建。

## 7. 不做事项

- 不持久化悬浮按钮位置。
- 不抽取只有一个调用方的通用拖拽组件。
- 不引入第三方拖拽库、背景图片或动画库。
- 不修改咨询/预约的目标路由和预约业务逻辑。
