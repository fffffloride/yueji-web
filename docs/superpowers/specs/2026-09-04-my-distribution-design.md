# 我的分销

日期：2026-09-04；状态：用户已确认并授权实现。

## 范围

分销身份只能由后台配置。个人中心服务列表首项增加「我的分销」，已通过和已禁用代理可见；无代理、待审核和已驳回不显示入口。身份查询失败提供重试，不能当成普通会员。每次进入业务页重新核验本人代理状态。

已禁用代理保留历史佣金、钱包提现、业绩、任务和只读资料，关闭团队入口与邀请码复制。用户不能申请或编辑代理身份；同时移除服务端 C 端申请路由、申请服务和 DTO。既有后台管理与服务端业绩升级规则继续使用。

## 页面与字段

1. 我的分销：复用 index，展示代理姓名、类型、等级；可提现、待核销、待结算、冻结金额；本月直属销售额、订单数、客户数；六个业务入口。
2. 佣金明细：复用 commission，状态筛选（全部、待核销、待结算、已结算、已冲销）、一级/二级与支付日期筛选；订单编号、基数、比例、金额、时间，卡片内展开详情。
3. 分销钱包：复用 wallet，展示可提现、冻结、累计已结算、累计已打款、结算周期、下次结算日期、单笔上限。提现表单使用底部弹层，记录按状态筛选并展开审核和打款信息。
4. 我的团队：复用 team，仅展示直属下级人数及成员姓名、状态、各自直属有效销售额。禁用代理不可进入。
5. 销售业绩：新增 analytics，本月/上月/自定义日期，直属销售额、订单数、去重客户数和销售额趋势。
6. 销售任务：复用 task，按服务端生命周期筛选，显示目标、当前值、进度与独立达标标记。
7. 任务详情：新增 task-detail，按 ID 读取本人任务，展示说明、有效期、目标和服务端进度。
8. 代理资料：复用 merchant 并改名，只读展示姓名、联系方式、类型、等级、状态、邀请码。

数据来自 `/api/v1/app/distribution` 下已有 profile、commissions/page、team、settlement/account、withdrawals、withdrawals/page、analytics/overview、tasks/page、tasks/:id。业务页直接接真实接口，不写 mock 业务数据。

## 交互与边界

- 分销与消费钱包分开；已结算不等于已打款，待核销不计入可提现。
- 提现金额输入为元，严格解析至整数分。校验正数、两位小数、可用余额和单笔上限。全部提现取余额与上限较小值。
- 后台 APPLY 模式允许申请，AUTO 模式隐藏申请按钮并说明自动生成后仍需审核和人工打款。
- 请求期间禁用重复提交。提交结果不确定时先刷新记录与余额，提示核对后操作，不自动重试 POST。
- 刷新、筛选与分页防止过期请求覆盖新结果；加载、无权限、空结果、首次失败和续页失败均可识别，失败不伪装为零余额。
- 日期使用原生 picker；业绩默认本月，统计时间与粒度使用服务端响应，销售趋势采用 CSS 条形图，无新依赖。
- 复用 YjPage、YjEmpty、现有分页与请求封装，分销页面共同使用身份加载逻辑和品牌样式。
