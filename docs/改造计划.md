- 订单状态以服务端枚举为准，不在页面自行推导或提前变更

### 页面

- 商品详情接通「加入购物车 / 立即购买」，规格和数量必须使用真实 SKU、库存与价格
- 完成 `src/pages/cart/index.vue`：选择、改数量、删除、失效提示和去结算

### 验收

- 登录 → 加购/立即购买 → 确认订单 → 创建订单 → 订单列表/详情 → 待付款取消

## 阶段 5：会员等级 + 积分 + 优惠券

### 接口与页面

- 新增 `src/api/marketing`，接入账户、积分流水、可领取券、领取和我的券
- 会员页展示当前等级、累计实付、积分余额与升级信息；积分页改接真实流水
- 优惠券页区分可领取、未使用、锁定、已使用和已过期状态
- 订单确认调用 `POST /api/v1/app/order/quote`，展示商品原价、等级优惠、券优惠、积分抵扣和应付
- 选券使用 `/api/v1/app/order/available-coupons`，创建订单只提交 `memberCouponId`、`pointsToUse` 和购买明细

### 固定交互约束

- 计价顺序固定为等级折扣 → 一张优惠券 → 积分；前端不得多券叠加或自行重算优惠
- 积分输入按服务端返回的兑换单位和最大可用积分校正；零元订单不进入支付页
- 取消、超时和整单退款后的券/积分状态重新请求服务端，不做本地乐观恢复

### 验收

- 领取/定向券 → 订单试算 → 选券与积分 → 创建订单 → Mock/零元支付 → 后台核销 → 等级与积分更新
- 待付款取消、超时取消和整单退款后，积分与有效优惠券正确恢复；过期券不恢复
